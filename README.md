# Simple Calculator

## Description
A beginner-friendly calculator built using Python.
It performs basic mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Error handling
- Menu-driven interface

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:

   python calculator.py

## Learning Concepts
- Variables
- Operators
- Conditional statements
- While loops
- Exception handling
